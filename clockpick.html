jQuery ClockPick Demo

This page documents the configuration options exposed by the plugin and demonstrates several ways to tailor the timepicker experience.

Option Type Default Description
starthourint8Starting hour for the picker range.
endhourint18Ending hour for the picker range.
showminutesbooltrueShows the minute picker when enabled.
minutedivisionsint4Number of minute divisions, such as 4 for quarter-hours.
militaryboolfalseUses 24-hour time formatting when enabled.
eventstringclickEvent used to trigger the picker.
layoutstringverticalSets the picker layout to vertical or horizontal.
valuefieldstringnullTargets a separate input field to receive the selected value.
hoursopacityfloat1Opacity for the hours container.
minutesopacityfloat1Opacity for the minutes container.

Default behavior

Click the field to open the picker using the plugin defaults.

Uses the default layout and range.
Example config 
$('#default-time').clockpick();

Custom hours and minute divisions

This demo narrows the range and shows quarter-hour increments.

Open from 9:00 to 17:00.
Example config 
$('#range-time').clockpick({
    starthour: 9,
    endhour: 17,
    minutedivisions: 6
});

Military and horizontal layout

This demo uses a horizontal layout and a 24-hour display.

Open on focus with 24-hour formatting.
Example config 
$('#military-time').clockpick({
    military: true,
    event: 'focus',
    layout: 'horizontal'
});

Target a separate field

This demo writes the selected value into another input and updates a status message.

Pick a time to populate the field.
Example config 
$('#callback-field').clockpick({
    valuefield: 'callback-output'
}, function(value) {
    $('#callback-status').text('Selected: ' + value);
});
