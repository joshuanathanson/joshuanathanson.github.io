jQuery Magnify Demo

This page documents the configurable options exposed by the plugin and demonstrates several ways to tailor its behavior.

Option Type Default Description
lensWidthint100Width of the magnifying lens in pixels.
lensHeightint100Height of the magnifying lens in pixels.
showEventstringmouseoverEvent used to display the large image.
hideEventstringmouseoutEvent used to hide the large image.
stagePlacementstringrightPlaces the zoom stage to the right or left of the thumbnail.
preloadbooleantruePreloads the large image before showing the zoom stage.
loadingImagestring''Path to a loading image or spinner.
stageCssobject{}Additional styles applied to the zoom stage.
lensCssobject{}Additional styles applied to the magnifying lens.
onBeforeShowfunctionfunction() {}Called immediately before the zoom is shown.
onAfterShowfunctionfunction() {}Called immediately after the zoom is shown.
onBeforeHidefunctionfunction() {}Called immediately before the zoom is hidden.
onAfterHidefunctionfunction() {}Called immediately after the zoom is hidden.

Default behavior

No options are passed. This uses the plugin defaults.

Example config 
$('#lambo-link').magnify();

Custom lens size

This demo uses a larger lens. The stage size is adjusted proportionally.

Example config 
$('#lambo-left-link').magnify({
    lensWidth: 140,
    lensHeight: 140
});

Toggle on click

This demo uses click events for showing and hiding the zoom view. The status text updates when the zoom view is shown or hidden.

Click the image to toggle zoom.
Example config 
$('#lambo-click-link').magnify({
    showEvent: 'click',
    hideEvent: 'click',
    preload: false,
    onBeforeShow: function() {
        $('#click-status').text('Showing zoom view...');
    },
    onAfterHide: function() {
        $('#click-status').text('Click the image to toggle zoom.');
    }
});

Custom styling and callbacks

This demo applies custom lens and stage styling and reports lifecycle callbacks.

Ready.
Example config 
$('#lambo-style-link').magnify({
    lensWidth: 120,
    lensHeight: 120,
    lensCss: {
        border: '2px solid #ef4444'
    },
    stageCss: {
        border: '2px solid #2563eb'
    },
    onBeforeShow: function() {
        $('#style-status').text('Showing zoom view...');
    },
    onAfterShow: function() {
        $('#style-status').text('Zoom view is active.');
    },
    onBeforeHide: function() {
        $('#style-status').text('Hiding zoom view...');
    },
    onAfterHide: function() {
        $('#style-status').text('Ready.');
    }
});
